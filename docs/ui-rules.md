# UI/UX Rules: Sentinel Mobile

## 1. Visual Identity
- **Color Palette**:
  - Background: `#000000` (Pure Black)
  - Primary: `#FFFFFF` (Tactical White)
  - Success/Neutralized: `#4ade80` (Green)
  - High Risk: `#ef4444` (Red)
  - Pending: `#f59e0b` (Amber)
- **Glassmorphism**: Use translucent overlays for HUD elements and cards.

## 2. Typography
- **Headers**: Bold Monospace for a "terminal" feel.
- **Body**: `Inter` for clarity.
- **Tracking**: Increased letter spacing for labels and HUD elements.

## 3. Interaction Design
- **Takedown Swipe**:
  - Right Swipe = "PURGE" (Action: Resolve)
  - Left Swipe = "IGNORE" (Action: Dismiss)
- **Feedback Loop**:
  - Haptic feedback on swipe completion.
  - Tactical toasts for status confirmation.

## 4. Components
- **HUD Elements**: Scanning lines, pulsing indicators for live data.
- **Tactical Cards**: Rigid borders, high contrast data points.
